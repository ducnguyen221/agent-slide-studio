Cài đặt

Cài một lần, dùng trong mọi phiên

Cần một agent có ImageGen sẵn (Codex, Claude Code hoặc Antigravity). Python 3 chỉ cần khi cài bằng installer, không cần để dùng skill.

Claude Code: cài như plugin

Cách nhanh nhất nếu bạn dùng Claude Code.

1

Thêm marketplace và cài

Terminal
claude plugin marketplace add ducnguyen221/agent-slide-studio
claude plugin install agent-slide-studio@agent-slide-studio
2

Mở phiên mới

Khởi động lại Claude Code để nạp skill.

Codex, Claude, Antigravity: dùng installer

Hợp khi muốn cài vào một dự án cụ thể hoặc cài cho cả ba agent.

1

Lấy mã nguồn

Terminal
git clone https://github.com/ducnguyen221/agent-slide-studio
cd agent-slide-studio
2

Xem kế hoạch rồi cài

Lệnh không có --apply chỉ in kế hoạch; thêm --apply mới ghi.

Terminal
# cài vào một dự án, cho một agent
python scripts/install.py --host codex --scope project --target "D:/Projects/du-an"
python scripts/install.py --host codex --scope project --target "D:/Projects/du-an" --apply
# hoặc cài cho cả ba agent ở mức cá nhân
python scripts/install.py --host all --scope user --apply

Lưu ý: đã cài plugin Claude Code thì đừng cài thêm bản installer cho Claude ở mức cá nhân, nếu không skill sẽ hiện hai lần.

Skill nằm ở đâu

AgentTrong dự ánMức cá nhânCách gọi
Codex.agents/skills/agent-slide-studio~/.agents/skills/skills hoặc $agent-slide-studio
Claude Code.claude/skills/agent-slide-studio~/.claude/skills hoặc plugin/agent-slide-studio
Antigravity.agents/skills/agent-slide-studio~/.gemini/config/skillsnhờ agent đọc skill agent-slide-studio

Kiểm sau khi cài

Kiểm gói trong thư mục tạm, không đụng dự án thật.

Terminal
python scripts/validate.py . --require-manifest
python scripts/test_package.py

Đúng khi: validate.py báo "errors": [], và trong agent gõ cách gọi ở bảng trên thì skill hiện ra.

Nâng cấp và gỡ

↑

Nâng cấp

Plugin: chạy lại lệnh cài. Installer: kéo bản mới rồi cài đè, bản cũ được sao lưu.

Terminal
git pull
python scripts/install.py --host all --scope user --overwrite --apply
×

Gỡ

Plugin gỡ bằng lệnh dưới; bản installer gỡ bằng cách xoá thư mục skill ở bảng trên.

Terminal
claude plugin uninstall agent-slide-studio@agent-slide-studio
claude plugin marketplace remove agent-slide-studio

Lỗi hay gặp

Installer báo «Hash payload sai»?

Lấy lại mã nguồn với dòng LF: repo đã có .gitattributes, nhưng bản clone bằng core.autocrlf=true trước đó cần checkout lại.

Installer từ chối vì thư mục đích đã có?

Thêm --overwrite --apply để nâng cấp; bản cũ được sao lưu ra ngoài vùng skill.

Skill hiện hai lần trong Claude Code?

Bạn đã cài cả plugin lẫn bản installer cá nhân; xoá bản trong ~/.claude/skills.
