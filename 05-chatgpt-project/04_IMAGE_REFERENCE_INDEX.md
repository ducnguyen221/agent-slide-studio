## Cách ghi reference decision

Trước khi tạo ảnh, ghi vào deck plan hoặc content lock:

```text
REFERENCE_OPENED: <tên file>
LEARN: <geometry / spacing / palette / icon / material / hierarchy>
DO_NOT_COPY: <text / facts / logo / claim / percentages>
```
