# Ánh xạ SmartArt và công cụ vẽ

Theo mô tả tại [S11–S12](sources.md). Mã L là thư viện của gói, không mã chính thức Microsoft.

| Nhóm quan hệ | Layout | Cách lắp |

| List / danh sách | L10, L18 | SmartArt List hoặc nhóm hình, không mũi tên giả |
| Process | L02, L05, L17, L21 | Process đơn giản; nhánh cần connector |
| Cycle | L12 | Cycle có điểm quay lại |

| Pyramid | L24 | Phân tầng; không giả tỷ trọng |
| Picture | L01, L20, L32 | Hình + chữ rời |
| Làn trách nhiệm | L22 | Hình/connector theo làn |
| Dữ liệu | L23, L28, L29, L34, L35 | Chart hoặc shape dựng theo số thực |

Ảnh minh họa kiểu SmartArt không là đối tượng SmartArt. Muốn sửa từng phần phải dựng
shape/text/chart hoặc SmartArt thật trong PowerPoint. Kiểm tra lại nghĩa khi đổi mẫu.
