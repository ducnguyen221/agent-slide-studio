# Sáu vai trò chuyên môn

- [Người thiết kế học liệu](instructional-designer.md): Làm rõ mục tiêu học tập, chia cụm và tách chữ hiển thị khỏi lời giảng.
- [Người tổ chức thông tin](information-architect.md): Chọn quan hệ và sơ đồ phù hợp, kiểm tra logic kết nối.
- [Người phụ trách thị giác](visual-director.md): Áp nhận diện, lề, chữ, màu và nhịp bộ trang.
- [Biên tập viên tiếng Việt](vietnamese-editor.md): Việt hóa chữ nhìn thấy và bảo vệ tên riêng cùng cú pháp.
- [Người kiểm chứng nội dung](fact-checker.md): Xác minh các khẳng định và phân biệt nguồn với đề xuất.
- [Người kiểm định độc lập](qa-reviewer.md): So sánh sản phẩm thực với brief, bản chữ và tiêu chí kỹ thuật.

Một agent có thể đảm nhiệm tuần tự các vai trò. Không cần khởi chạy sáu agent để sửa một tiêu đề.
Adapter Claude Code là tùy chọn riêng. agents/openai.yaml chỉ là metadata Codex, không phải khai báo sáu subagent.
